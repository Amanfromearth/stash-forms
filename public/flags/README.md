# Country flags

The main set contains 226 SVG flags from [Nucleo's free flag collection](https://nucleoapp.com/svg-flag-icons), obtained from its official free Vanilla bundle, version 0.1.14.

The 23 ISO territories absent from that collection use SVGs from [lipis/flag-icons](https://github.com/lipis/flag-icons), framed to the same 32px grid with rounded corners. These are covered by the included `LICENSE.flag-icons` (MIT, copyright 2013 Panayiotis Lipiridis).

Supplementary codes: AS, BL, BQ, BV, CC, CX, GU, HM, IO, MF, MP, MS, NF, PM, PN, RE, SH, SJ, TF, TK, UM, WF, YT.

Flags are served locally; the country names remain the questionnaire's original saved answer values.
